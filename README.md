# Actividad Unidad III - Node JS + Express

Backend desarrollado con Node.js y Express para el control de tareas y metas personales (To Do List).

La aplicación permite agregar, listar y eliminar tareas y metas utilizando endpoints REST y un middleware de autenticación mediante API Key.

---

## 📌 Requisitos
- Node.js (versión LTS recomendada)
- npm

---
